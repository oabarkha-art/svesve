# Cocomat Pro Medium

Diese Website verwendet die Schriftfamilie **Cocomat Pro**, Schnitt **Medium (500)**.

Lege die rechtmäßig lizenzierten Schriftdateien in diesem Verzeichnis ab:

- `cocomat-pro-medium.woff2` (bevorzugt)
- `cocomat-pro-medium.woff` (alternativ)

Beide Pfade sind bereits in `client/src/index.css` per `@font-face` eingebunden. Fehlen die Dateien, verwendet der Browser automatisch `system-ui, -apple-system, "Segoe UI", sans-serif`. Schriftdateien bitte nicht aus unautorisierten Quellen übernehmen.
